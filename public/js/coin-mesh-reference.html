Height Map — 4-Tier Elevation Reference

The height map is a grayscale canvas texture sampled in the fragment shader. The shader's smoothstep(0.15, 0.02, heightValue) creates the _deepMask that controls starfield visibility.

1.0 — Frame / Accents / Text
0.70 — Inner Panel Surface
0.30 — Groove Edge Ramp
0.0 — Starfield Window
Height ValueGray HexFeatureShader Effect
1.0#ffffffBrass frame edges, corner accents, text, suit icon, classified stamp, border ringsMaximum brass reflection, full metalness, no starfield. Defines the coin's highest physical relief.
0.70#b3b3b3Inner content panel surface (default fill)Standard mid-tone appearance. The neutral plateau for colored panel and content elements.
0.30#4d4d4dGroove edge ramp and shadow blurTransition ramp. _deepMask begins to activate faintly. Soft edge into groove.
0.0#000000Deep groove channels (starfield window)_deepMask = 1.0. Diffuse darkened 96%, metalness reduced 88%. Starfield emission at 1.6x.

Shader Injection Points (Three.js r128)

The coin material uses MeshStandardMaterial.onBeforeCompile to inject custom GLSL into four shader chunks. The shader reads the height map and a shared starfield texture.

Injection PointChunk NamePurpose
1. Declarationsmap_pars_fragmentDeclares uniform sampler2D heightMap, starfieldTex and float _deepMask.
2. Height maskmap_fragmentSamples height map, computes _deepMask = smoothstep(0.15, 0.02, height). Darkens diffuse in deep areas.
3. Metalnessmetalnessmap_fragmentReduces metalnessFactor by _deepMask * 0.88 so starfield emission isn't reflected away.
4. Emissionemissivemap_fragmentSamples starfield texture with parallax offset, adds to totalEmissiveRadiance scaled by _deepMask * 1.6.
The chunk output_fragment does not exist in Three.js r128. Starfield is added as emission so it flows through ACES Filmic tone mapping correctly.

Mission Object Schema

The MISSIONS array in splash-screen.js defines the data for each card. The 3D renderer consumes these fields to generate textures:

FieldTypeUsed InDescription
titlestringFace, Height, BumpPrimary text, rendered uppercase at h * 0.72. Bold monospace, white on colored panel.
descstringFace, HeightSubtitle at h * 0.78. Smaller monospace, white on colored panel.
suitUnicode charFace, Height, BumpCentral emblem (♠ ♣ ♥ ♦) at cx, h * 0.44. Dark silhouette on panel. Determines color palette.
classifiedstringFace, HeightSecurity stamp at h * 0.10. White text on brass frame. Raised on height map.
labelstringFace, HeightCategory label at h * 0.135. Small monospace, white on brass frame.
suitClassstringCSS onlyCSS class for suit coloring. Not used by 3D renderer.
durationstring|nullSplash CSSBooking duration label. Not rendered on coin texture.
routestringSplash clickNavigation URL when card is selected. Not rendered on coin.

Texture Generation Pipeline

Mission Object
     │
     ├─→ _cardPalette(m)     → {bg, mid, hi, glow, name}
     │
     ├─→ genFaceTex(m)        → CanvasTexture → material.map
     │     brass frame → groove channels (dark) → colored inner panel
     │     → corner accents → suit silhouette → white text → starfield windows
     │
     ├─→ genHeightMap(m)     → CanvasTexture → shader uniform heightMap
     │     1.0 (white) frame/accents/text → 0.70 gray panel → 0.30 groove ramp
     │     → 0.0 (black) groove channels (starfield window)
     │
     ├─→ genBumpTex(m)       → CanvasTexture → material.bumpMap
     │     matching relief with raised frame/text and depressed grooves
     │
     └─→ _getStarfield()     → CanvasTexture → shader uniform starfieldTex
           one shared canvas, sparse 1-3px stars, faint nebula wisps
           deterministic pseudo-random placement, shared across all 4 cards
