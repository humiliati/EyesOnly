Sound Designer Portal — Quick Reference

Sound Library (Left Sidebar)

315 sounds organized into 12 categories: UI, Movement, Combat, Magic, Environment, Collectible, Creature, Footsteps, Card Sounds, Music — Songs, Music — Cyberleaf, Music — Aila Scott. Click any entry to select it. Use the search bar to filter by name, ID, or title. Category headers collapse/expand on click.

The library is baked as static HTML — it works offline without fetching the manifest. When the manifest loads, it enriches metadata (tags, volume overrides, etc.).

Preview (This Panel)

Select a sound, then hit Play to stream it. The waveform visualizer shows live audio data via AnalyserNode. Volume slider adjusts in real-time during playback. Works for both short SFX and full-length music tracks (streaming, no full download).

Assignment

Wire sounds to game entities. Select a sound in the library, switch to the Assign tab, pick a context (Asset, Map, Interior), choose an entity, then click the assign button on any event slot. Assignments persist in localStorage and can be exported as JSON.

Upload

Drag audio/video files into the dropzone (max 50MB each). Choose a destination folder (sfx, music, video) and click Upload All. Files go to the eyesonly-assets R2 bucket. Supported formats: .wav .mp3 .ogg .webm .m4a .mp4 .opus

Inspector (Right Panel)

Shows metadata for the selected sound: key, source path, category, loop flag, display name, tags. Edit fields to override properties. The "Assignments" section shows everywhere this sound is currently wired.

Header Actions

Refresh — re-fetches the manifest from the worker for metadata enrichment.
Save Assignments — persists current assignments to localStorage.
Export JSON — downloads sound-assignments.json mapping file.

Keyboard Shortcuts

Space — Play/Pause preview
Escape — Stop preview

Using from File System

The portal works when opened directly from disk (file://). All audio fetches are automatically rebased to https://flapsandseals.com. The manifest fetch is optional — the static library functions without it.

Audio Pipeline

Assets on R2 are available in both WAV (original) and WebM/Opus (transcoded) formats. The manifest src fields reference WAV paths; both formats resolve from R2. MP3 fallbacks also exist for Safari < 15.4.

Footstep System

8 stereo footstep samples (L/R × 4 terrains: dirt, grass, sand, stone) are served from R2. The runtime AudioSystem.playFootstep(biome, isInterior, running) automatically selects terrain based on biome and alternates left/right. Interior floors default to stone. Running mode increases volume and pitch.
