ROGUE HELP — ACCESSIBILITY Controller input & game-wide accessibility features

QuadStick Controller Support

Gone Rogue supports the QuadStick mouth-operated gamepad controller via the browser Gamepad API. No drivers or plugins are required — plug in the QuadStick and the game detects it automatically once controller mode is toggled on in the [Accssblty] row of the debrief panel.

How it works

The QuadStick sends joystick axis values and button events through the standard Gamepad API. A lightweight adapter maps these to the three fishing-preview hooks that GoneRogueMobile exposes:

GoneRogueMobile.beginFishingFromPlayer() // aim gesture starts GoneRogueMobile.updateFishingTarget(x, y) // cursor moves → path preview GoneRogueMobile.commitFishingTarget(x, y) // confirm → player moves

These hooks reuse the same A* pathfinding and path-overlay rendering that touch/mouse dragging uses, so the visual feedback is identical.

QuadStick input mapping

Sip (soft) → hold to aim (beginFishingFromPlayer) Lip left/right → move grid cursor left/right Lip up/down → move grid cursor up/down Puff (hard) → commit move (commitFishingTarget) Sip (hard) → cancel aim (hides preview, resets) Button A → tap nearest cell (tap-to-move) Button B → open card fan (action menu)

Full axis-to-tile mapping and polling is handled by the gone-rogue-quadstick.js adapter (loaded separately when QuadStick mode is enabled).

Enabling QuadStick mode

  • Open the debrief panel during a Gone Rogue run.
  • Tap [Accssblty] to expand the accessibility row.
  • Toggle QuadStick [OFF → ON].
  • The setting persists across sessions via localStorage.

High-Contrast Mode

Increases visual contrast across the game UI: brightens the grid overlay, strengthens text shadows, and removes low-opacity tints on labels. Useful for low-vision players or bright-environment play.

Abbreviation Convention

The debrief panel uses a vowel-drop abbreviation scheme throughout (e.g. resources → Rsrcs, accessibility → Accssblty). Labels keep the first letter of each word regardless of vowel/consonant, then drop all non-first vowels. This keeps the terminal aesthetic while staying readable for screen-reader users (full names are in aria-label attributes where present).

Keyboard & Touch Fallback

All movement and actions are accessible without a mouse or controller:

  • WASD / N S E W — directional movement
  • Click / tap grid cell — tap-to-move (A* pathfinding)
  • Hold + drag — fishing-mode path preview, release to commit
  • Double-tap cell — sprint mode
  • Tap player (@) — open card fan / action menu
  • TAKE / EXTRACT / STATUS / INVENTORY — text commands always available
