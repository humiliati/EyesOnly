Technical Details

Bug #1: Dual Currency Animation

Root Cause: Currency objects stay in _currencies[] array with collected=true flag, but renderer doesn't check this flag.

// BROKEN CODE (gone-rogue-mobile.js ~L725-736):
currencies.forEach(function(currency) {
  var vx = _toViewX(currency.x);
  var vy = _toViewY(currency.y);
  if (!_inView(vx, vy)) return;
  entities.push({  // ← Renders ALL currencies, even collected ones!
    x: vx, y: vy,
    char: currency.glyph || '¢',
    color: '#FFFF00'
  });
});

Fix: Filter out collected currencies in the rendering loop.

// FIXED CODE:
currencies.forEach(function(currency) {
  if (currency.collected) return;  // ← Skip collected currencies!
  var vx = _toViewX(currency.x);
  var vy = _toViewY(currency.y);
  if (!_inView(vx, vy)) return;
  entities.push({
    x: vx, y: vy,
    char: currency.glyph || '¢',
    color: '#FFFF00'
  });
});

Bug #2: Food/Interactive Items Not Removed

Root Cause: Items are rendered from BOTH _items[] AND InteractiveItems._interactiveItems[]. Collection removes from one but not the other.

// BROKEN: Two separate rendering loops (gone-rogue-mobile.js L739-751, L787-799)
// Render from _items[]
items.forEach(function(item) { entities.push({...}); });
// ...
// Render from InteractiveItems (separate system!)
interactiveItems.forEach(function(item) { entities.push({...}); });

Fix: Deduplicate items by position before rendering, or ensure removal from both systems.
