Manual Testing Instructions

To manually test vents in Gone Rogue:
  1. Start Gone Rogue from the main terminal (command: ROGUE)
  2. Navigate through floors until you encounter a 'V' tile (vent)
  3. Move to the vent tile and use INTERACT command
  4. First INTERACT discovers the vent, second INTERACT attempts bypass
  5. Success: Skip to floor N+2
  6. Failure: Backtrack 3 floors with penalty enemies (marked 🔻)
To test floor shuffling:
  1. Start multiple Gone Rogue runs
  2. Note the biome on each floor (displayed in status line)
  3. Verify variety in biome selection after floor 4
To test biome bleed:
  1. Play Gone Rogue and advance floors
  2. Look for tiles from previous/next biomes near edges
  3. Grass (,) from Forest, debris (░) from Mall/Aerospace, etc.
